Changed

- The dashboard is rewritten on React 19 and the Astryx design system, with a side navigation. Old hash links redirect to the new pages, and a tab opened before an upgrade reloads once to pick up the new build. (#1)
- Overview shows a status summary (accounts that can serve, requests, failure share), attention cards for problems such as missing client keys or unreachable upstreams, and request charts by time and by source. (#1)
- Accounts lists credentials with search and filters, per-account details and upstream errors, and actions to upload files, check quotas, refresh a token, reset a cooldown, disable and delete. Provider keys are managed on the same page in groups. (#1)
- Connect adds an account step by step, with progress shown, and a first-run guide walks through connecting an account and a client key. (#1)
- Client keys can be added, revealed, copied and revoked from the row actions. (#1)
- "Use with a tool" gives a three-step setup for each coding tool and tests the client key against the proxy. (#1)
- Models manages aliases and excluded models, and Payload rules adds, edits and removes the rules that change request bodies. (#1)
- Usage charts requests and failures per ten minutes, by source and per model, with an opt-in live view of recent requests that shows model, latency and tokens. (#1)
- Logs shows the application log and the error log files with follow, search by text or request ID, level filters and Clear. (#1)
- Settings edits the configuration through grouped controls or as the raw configuration file, and shows a review of the changes before saving. Plugins, About and the System dialog open from the dashboard. (#1)
- The dashboard is available in English, Simplified Chinese and Traditional Chinese, and only the active language loads. (#1)
- Light and dark themes switch with one click, and Dark Reader is kept out of the dashboard. (#1)
- Signing in lasts for the tab by default; "Remember on this device" keeps the key in the browser, and the browser's password manager can save it. Signing out in one tab signs out every tab and cancels sign-ins in progress. (#1)
- Saving a configuration change no longer overwrites a newer one made elsewhere. (#1)
- Charts load on demand, and the first load is 334 KB of JavaScript and 48 KB of CSS, gzipped. (#1)
