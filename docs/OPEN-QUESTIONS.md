## Settled

- 1, 2026-11-13: model or tool attribution is not a hard limit in this repository; agents add none and leave the PR template's disclosure checkboxes to the human submitter (「AI 署名不禁止把 但是我们还是不要加这个」).
- 2, 2026-11-13: the owners are Zakkaus, xz-dev, Glassyiris and JohnsonRan; a release or replacing Core's running proxy also needs Vayun's approval (「多人共同 owner」).
- 3, 2026-11-13: the dashboard signs in with a server-issued session cookie, 7 days by default and 30 days when remembered; no key or token in script-readable storage (「预设时间可以长一点7天都行」). Implementation gap and due date: `REQUIREMENTS.md`, "Not yet enforced".
- 4, 2026-11-13: the optional Rosé Pine palettes are excepted from WCAG AA; default Neutral meets AA (「主題的話是例外的」).
- 5, 2026-11-13: proposed in the installation PR and settled when an owner approves it: Model usage keeps generic selection, independent review and served-model checks; run provenance stays out of the repository.
- 6, 2026-11-13: the rules are installed by the PR adding this file (「改把 agents.md的先pr才行」).
- 14, 2026-11-13: no backward compatibility in any surface; cook-router is a full rewrite of an existing project (「完全不需要考虑任何向后兼容性，我们是基于一个现有项目的完整重写」). Recorded in `REQUIREMENTS.md`, "Exceptions".
- 15, 2026-11-13: the project goal is an efficient AI gateway focused on routing and scheduling, modularity and structure (「新的项目的目标是设计一个高效的 AI 网关，主要专注在路由与调度以及模块化和结构性上」). Recorded in the opening of root `AGENTS.md`.
- 16, 2026-11-13: inside the router every transport protocol is abstracted as an SSE event stream in an internal format extending OpenAI's SSE format with extra attributes; conversion happens only at ingress and egress, and internal processing works on the unbounded SSE stream (「路由器内部改用 SSE 加额外属性的方式抽象各个传输协议，并只在入口和出口进行转换为内部的基于 OpenAI 的 sse 格式拓展的格式，内部处理完全采用 SSE 无边数据流的处理」). Recorded in `crates/AGENTS.md`, "APIs and modularity".
- 17, 2026-11-13: no raw-byte passthrough and no old paths: every request is converted at ingress and egress, and a rewrite is written once with no legacy code left (「不需要无谓的旧路径，我说过这是重写，没有所谓的旧的新的要写就一次写好避免遗留旧代码未处理」). Non-SSE payloads use fixed chunks of at most 50 KB with at most 100 ms collection delay (「串流使用自定义数据固定分块，每一个块上限50kb，收集延迟最长100ms」). Attributes use reserved JSON fields plus named `event:` events (「好的」). The plugin SDK and store migration is owned by this project's maintainers (「你方」).
- 18, 2026-11-13: the internal SSE stream is read and written through mmap-backed files; the router holds only file handles (「然后内部 SSE 流使用 mmap 的方式直接读写进文件，我们只持有文件指针」). Recorded in `crates/AGENTS.md`, "APIs and modularity"; file location, lifecycle and limits are settled in the stream specification.
- 19, 2026-11-13: no heap memory as SSE stream storage; only the key positions are kept, and the stream uses fixed-size blocks modelled on operating-system memory management, so no pointer per block is needed (「不使用内存作为 sse 流的存储，只保存sse流的关键指针位置，以及我们参考操作系统内存的管理方式，对sse使用固定分块，这样不需要持有多个指针」).
- 20, 2026-11-13: the internal format is based on OpenAI Chat Completions chunks, because the design is chunk-based (「OpenAI Chat Completions chunk 因为我们的设计逻辑本身就是 chunk」); attributes use reserved JSON fields plus named `event:` events; the reserved prefix is `x_cook_router`; unknown fields and events are always kept and passed to egress (「一律原樣保留並傳到出口」).
- 21, 2026-11-13: supported targets are the Linux server and the browser dashboard; Windows is not supported for now (「暂时不需要考虑 Windows 支持，我们暂时考虑的支持目标是 Linux 后端加前端浏览器」). Recorded in root `AGENTS.md`, "Scope".
- 22, 2026-11-13: when stream storage is full, use a first-in-first-out cache queue limited by size and age; other cases such as a full disk are best effort with no special handling (「写满处理，先进先出缓存队列，限制大小和缓存时间，其他情况比如磁盘写满，则尽力而为，不处理边界情况」).
- 23, 2026-11-13: crashes caused by resource exhaustion are left to the operating system and reported plainly to downstream services; service degradation is the cluster's job, and cook-router is a single service (「我们认为资源导致的崩溃应该操作系统承担处理工作，并且可以明显告诉下游服务异常，因为服务降级是集群应该处理的事情，我们目前设计是单体服务模块」). Recorded in `crates/AGENTS.md`, "Operations (if present)".
- 24, 2026-11-13: no installer in any form, including custom scripts run inside Docker; the first release target is a Docker image only, published to GitHub Packages (「不要提供任何形式的（包括 docker 里面跑自定义脚本的安装器）安装器，我们的第一个发布目标是只提供 docker image」「发布到 GitHub package」).
- 25, 2026-11-13: `master` gets no required merge checks; the project is unstable and checks must not block development (「不要设置 master 合并质量，目前项目不稳定不要阻碍开发」). Recorded in root `AGENTS.md`, "Merging".
