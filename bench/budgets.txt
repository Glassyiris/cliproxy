# Performance budgets, checked by bench/gate.sh (size, idle) and by
# crates/cpa-server/tests/alloc_budget.rs (heap per request) on GitHub-hosted runners.
#
#   <key> <value> <tolerance %>
#
# A measurement fails when it exceeds value * (1 + tolerance / 100).
#
# The size lines are ceilings with headroom, not the last accepted measurement. A pull
# request that grows the binary does not edit this file: the CI report comment on the pull
# request (.github/workflows/report.yml) shows every size and Linux idle number next to
# master's and the ceiling. Raise a line only when a change needs it, with a maintainer's
# approval, and give the reason next to it. Counts that must stay near zero have no
# tolerance.
#
# Every budgeted number comes from one pinned compiler (RUST_TOOLCHAIN in the workflows).
# A toolchain bump re-measures the measured budgets (idle, soak and heap) in the same pull
# request, with a dated line:
#
#   # 2026-10-06: Rust 1.99.0.
#
# A key without a line is reported and not gated, so a new target or metric starts by
# reporting. Targets from docs/BENCHMARKS.md that these do not meet yet are noted next to
# their lines.

# 2026-10-06: Rust 1.99.0.
